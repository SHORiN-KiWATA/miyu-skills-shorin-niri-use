# Operating the niri desktop (shorin-niri-use)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a community skills package for [Miyu](https://github.com/miyu-agent/miyu) that contains one skill, `niri-agent`. The skill lets the AI operate graphical applications on the niri desktop in the background (capturing windows, clicking, typing, pressing keys, launching applications) without moving your cursor or changing your focus; anything that can be done through the command line or D-Bus is done that way first.

Install it by running:

```sh
miyu pkg install shorin-niri-use
```

After installation, the AI normally sees only the skill's name and a one-line description, and reads the skill's full text itself when it needs to operate the desktop; you can also write `$niri-agent` in the input box to ask the AI to use the skill by name.

## Requirements

To use the skill, you need the following:

- **[SHORiN-KiWATA/niri](https://github.com/SHORiN-KiWATA/niri)**: `niri msg agent` (the agent seat, a second pointer and keyboard) is a feature added by this fork. Official niri does not have it, so the skill cannot be used with official niri.
- `agent-firefox` needs `rsync` to sync website data (`storage/`).
- `agent-ui` (which reads a window's accessibility tree) needs PyGObject and AT-SPI: run `python3 -c "import gi; gi.require_version('Atspi', '2.0')"`, and if it reports no error, the requirement is met.
- The Miyu core must be started from within the desktop session, so that the core can reach niri's socket and the session's D-Bus.

## What is in the package

The package contains these three files:

| File | Contents |
|---|---|
| `skills/niri-agent/SKILL.md` | The skill's text: first look for a command-line interface, then choose a window, locate the target → act → check the reply, and finally the caveats and what to do about errors |
| `skills/niri-agent/agent-ui` | Lists the controls in a window and where to click (AT-SPI); faster and more accurate than screenshots |
| `skills/niri-agent/agent-firefox` | Opens a Firefox dedicated to the Agent, with your current login state |

The skill's text and the two scripts are rewritten from `resources/agent/skill/` in the niri fork: the tool names are replaced with Miyu's tool names (`shell`, `read`, `web_fetch`), and the scripts are looked up relative to the skill's folder. When the niri fork changes, this package changes with it.
